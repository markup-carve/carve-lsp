# carve-lsp

Language server for Carve 0.1 documents. It uses the Carve JavaScript engine to provide diagnostics, navigation, completion, and formatting. See the [Carve documentation](https://markup-carve.github.io/carve/).

Editor support includes diagnostics, completion, navigation, rename, formatting, and quick fixes.

## Install

```sh
npm install -g @markup-carve/carve-lsp
```

## Usage

```sh
carve-lsp --stdio
```
